# Project management wireframes

Open [project-management.svg](project-management.svg) in a browser and zoom in to view the screens.

1. **Projects:** Supervisors see active projects by default. They can include archived projects in the list and create, edit or archive a project.
2. **Create project:** A name is required and can contain up to 100 characters. The description is optional and can contain up to 2,000 characters.
3. **Edit project:** Supervisors update the name and description. Existing tasks and recorded time remain attached to the same project.
4. **Archive project:** A confirmation explains that history remains available. Archiving is refused while the project has active Intern assignments. Archived projects do not accept new tasks or assignments.
5. **Manage Intern assignments:** This is a planned screen for the separate assignment task. It is included in Sasha's wireframes, but its implementation is outside the project create/edit/archive task. Only an active internship can be assigned, and it can have at most one active project assignment.

An empty project list should show **No active projects available** and the **New project** action. Field errors should appear below their input. Successful changes should refresh the list and show a short confirmation.

The full board is 1,600 × 1,840 pixels. The wireframes describe screen layout and behaviour; they are not clickable prototypes.
